## Flowbench configuration

The native Flowbench contract accepts:

- `key_fields`: input field names copied to each generated row.
- `columns`: ordered output definitions with a unique output `name` and `mode` in `literal`, `field`, `field_name`, `field_description`, or `empty`.
- `rows`: rectangular matrix of strings or nulls. Each input record emits one output record for each configured matrix row, in input-record then matrix-row order.

`field` cells reference input fields and preserve/unify their types; heterogeneous source values are cast to the resulting field type. `field_name` emits the configured source name; `field_description` emits input metadata; `literal` emits the configured text; `empty` emits null. Selected key names must exist and cannot collide with output names. Invalid/missing references, duplicate output names and ragged matrices fail validation.

Desktop configuration uses the existing schema-driven Inspector. It exposes key-field selection and structured column editing; the row matrix is editable as JSON. Imported Alteryx Arrange XML is currently preserved as unknown configuration and is not translated into this native contract.

## Independent tests and limits

`tests/test_fe_tools.py` covers keyed multi-row expansion, decimal type preservation, metadata/name/literal cells, null input values, empty input schema, missing fields and invalid row widths. Automated status is generated by `scripts/build_status.py` from registration and executed test attribution.

Not tested against Alteryx: cell-mode semantics, row ordering, output type inference, configuration defaults, XML conversion, E1/E2 behaviour, or large-data performance. In particular, the Flowbench matrix contract must not be inferred to match each observed Designer XML element. Unsupported imported configurations must not be reported as equivalent.

No external dependency is required.

## Evidence limits

This is not reference verified and does not claim Alteryx parity. The specific unverified behaviours are listed above; no differential result is available.
