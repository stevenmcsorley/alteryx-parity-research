## Data quality flags

- The offline 323-entry tool list is a manual transcription of public names/categories. Public XML IDs and roles also transcribed; tool-page links and independent confirmation need internet enrichment (`scripts/sync_official_catalog.py`).
- Counts include duplicate category appearances and categories with add-ons/deprecations. They do not assert how many separate executable implementations are needed.
- The site serves a rolling `current` catalogue; use version-specific installed reference validation before declaring full 2026.1 coverage.
- Some older pages or help entries may reflect 2026.2 or other versions; always pin actual build and document source retrieval timestamps.
